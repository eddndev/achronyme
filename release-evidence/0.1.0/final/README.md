# Achronyme 0.1.0 final proving evidence

Status: the production BN254 Groth16 proving gate completed successfully for
source commit `fd07b38e16256e2ed6a8f2b438d340a681c9b0ac`.

This directory contains the public, byte-safe evidence for the final phase-2
beacon and both proof interoperability directions required by
`docs/proving/boss-fight-release-gate.md`. It contains no witness values,
private inputs, contributor entropy, toxic waste, phase-1 bytes, R1CS bytes,
or proving-key bytes.

## Binary rebuild receipt

The historical pre-beacon checkpoint records an earlier release binary with
SHA-256
`fd580091de194ea1f3e43633fbb0298abe5902581306a929b6280c30473dc4a2`.
That binary was no longer available after its disposable compute host was
removed. Rebuilding the same source produced the finalization binary above;
the two binaries are not byte-identical, so this dossier makes no bit-for-bit
binary reproducibility claim.

The rebuilt binary performed a fresh bounded export. Its R1CS and witness are
byte-identical to the artifacts used to create the independently contributed
zkey. `bossfight-export.json` binds the rebuilt binary, exact source, fixture,
R1CS, witness, sizes, and constraint counts. The finalizer rejected any
mismatch before applying the beacon or creating the trusted-key store.

## Interoperability results

All 13 measured finalization stages have exit status zero. In particular:

1. snarkjs generated a proof, and both snarkjs and Achronyme verified it;
2. Achronyme generated a proof from the trusted store without local setup,
   and both Achronyme and snarkjs verified it;
3. the R1CS regenerated by the native trusted proof is byte-identical to the
   ceremony R1CS.

The public proof, public-input, and verification-key JSON files are under
`interop/`. They carry no witness values. The exact stage timings and maximum
RSS values are in `metrics.json` and the three `*.metrics.jsonl` files.

## Public files

- `release-evidence.json`: canonical finalizer output and gate booleans;
- `bossfight-export.json`: bounded fresh export bound to the final binary;
- `trusted-key-manifest.json` and `ceremony-transcript.json`: public metadata
  copied from the privately retained trusted store;
- `metrics.json`: canonical finalization metrics;
- `export.metrics.jsonl`, `prepare.metrics.jsonl`, and
  `finalize.metrics.jsonl`: measured stage receipts;
- `interop/`: proof interoperability artifacts for detached re-verification;
- `verification-summary.txt`: compact ASCII operator receipt;
- `SHA256SUMS`: checksums for every public file except itself.

Run these checks from this directory:

```text
sha256sum --check SHA256SUMS
jq -e '.verification | all(. == true)' release-evidence.json
snarkjs groth16 verify interop/snarkjs-verification-key.json \
  interop/snarkjs-public.json interop/snarkjs-proof.json
snarkjs groth16 verify interop/snarkjs-verification-key.json \
  interop/achronyme-public.json interop/achronyme-proof.json
```

With the exact Achronyme release binary, also run:

```text
ach verify --curve bn254 --format json \
  --proof interop/snarkjs-proof.json \
  --public interop/snarkjs-public.json \
  --vkey interop/snarkjs-verification-key.json
ach verify --curve bn254 --format json \
  --proof interop/achronyme-proof.json \
  --public interop/achronyme-public.json \
  --vkey interop/achronyme-verification-key.json
```
